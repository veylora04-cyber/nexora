Design system

The component layer every NEXORA screen is assembled from. Values come from tokens.css; no screen defines its own colour, radius or spacing.

Colour

semantic tokens

Two families carry the identity: turquoise for product surfaces and actions, saffron reserved for AI, live and attention states. Neutrals are a cool graphite so the turquoise sits native rather than pasted on. Swatches read live values — switch the theme to compare.

Typography

2 families

Instrument Sans for Latin, Vazirmatn for Persian. Persian never receives letter-spacing (it breaks joining) and is set one step larger with more leading. Numbers use tabular figures; Persian renders Eastern Arabic numerals through Intl.

Accessibility

target WCAG 2.2 AA
Focus
  • Every interactive element has a visible :focus-visible ring — 2px, 55% opacity, offset by the control radius.
  • Focus order follows reading order in both directions; the skip link is the first tab stop.
  • Overlays close on Esc and on scrim click; the drawer moves focus to its close button.
Contrast
  • Body text on background: 12.9:1 (dark) · 15.8:1 (light).
  • Primary action label on primary fill: 6.4:1 (light) · 9.1:1 (dark).
  • Signal (saffron) is never used for small text on light backgrounds below 4.5:1.
  • State is always conveyed by text or icon as well as colour.
Motion
  • All transitions collapse to 0ms under prefers-reduced-motion.
  • One orchestrated entrance per page; nothing loops.
Targets
  • Controls are 40px high by default, 48px on large; icon buttons are 36px with 28px for dense table rows.
  • Touch targets on mobile are padded to 44px minimum.
